A travel poster for KHARUN — a place that does not exist. A cliff city of rose salt rock strung with hanging lanterns, seen at dusk across the salt desert, a camel caravan walking toward its lights.

## Run it

```sh
node main.ts
```

It writes the poster to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`), the same bytes on every run.
